## Descripción del proyecto

Este proyecto consiste en desarrollar un sistema de consola para administrar el catálogo de productos de una tienda. Permite consultar productos, agregar existencias, registrar nuevos artículos y calcular el valor total del inventario.

## Funcionalidades principales

1. **Búsqueda de productos:** permite consultar los datos de un producto mediante su código.
2. **Ingreso de existencias:** permite aumentar las unidades disponibles.
3. **Registro de productos:** permite agregar nuevos artículos al catálogo.
4. **Cálculo del inventario:** calcula el valor total de los productos disponibles.
5. **Visualización del catálogo:** muestra todos los productos registrados.
